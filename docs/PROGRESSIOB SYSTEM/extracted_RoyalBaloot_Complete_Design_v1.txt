3. RP Philosophy — Clean Skill Measurement
The client's position is correct. RP should reflect competitive skill only — wins, losses, and the strength of the opponents faced. Game mechanics like Kabout, Baloot, Qaid and Sawa should never affect competitive rank.
3a. Why removing game mechanic bonuses is the right decision
Kabout is partly luck-dependent — the cards dealt determine how many tricks are possible. Rewarding it with RP would let fortune influence rank.
Baloot (K+Q of trump) depends entirely on which cards the player is dealt. It is not a strategic choice — it is a lucky hand.
Qaid and Sawa penalties on RP would make players hesitant to use these features. They are meant to be natural gameplay tools, not risk calculations for rank.
Daily mission RP rewards would let consistent daily players outrank better players purely through grinding volume. Rank should reflect skill, not hours played.

8. 2v2 RP Calculation — Team Average Method
Because Baloot is always a 2v2 game, RP changes must be calculated using team averages. Both players on the same team always receive exactly the same RP change. Individual player RP is never used directly for opponent strength comparison.
8a. Step-by-Step Calculation
Step
Formula
Example result
1. Calculate Team A average RP
(Player1_RP + Player2_RP) ÷ 2
(2,000 + 1,800) ÷ 2 = 1,900 RP
2. Calculate Team B average RP
(Player3_RP + Player4_RP) ÷ 2
(2,300 + 2,100) ÷ 2 = 2,200 RP
3. Map each average to level index
RankSystem.getLevelInfo(avgRP).level.index
1,900 → محترف (index 3) | 2,200 → خبير (index 4)
4. Calculate level gap
Opponent index − My index
4 − 3 = +1 (Team B is stronger)
5. Apply modifier
Base 20 + (gap × 4)
20 + (1 × 4) = 24
6. Team A wins
+ 24 RP to Player 1 AND Player 2
Both teammates get +24 RP
7. Team B loses
- 24 RP to Player 3 AND Player 4
Both teammates lose 24 RP
8b. Special Cases
Scenario
Rule
Mixed rank team (e.g. أمير + مبتدئ)
Use team average. The strong player carries rating responsibility for their partner. Encourages equal-rank pairings.
Bot in the team or against bots
Bot is always treated as مبتدئ (index 0) for team average calculation. Win vs bot team: max +8 RP. Loss vs bot team: 0 RP loss.
All 4 players same rank
Level gap = 0. Base +20/-20 applies with no modifier.
Player disconnects mid-game
Disconnecting player loses full RP as if they lost. Their partner loses half. Opposing team wins half RP. Server enforced.
Player abandons Cup match
Full Cup ticket is consumed. Full -35 RP loss applies. No refund.
3 bots vs 1 real player
Real player vs bot team: max +8 RP on win. Should never occur in Cup (bots not allowed there).
8c. Dart Code — Team RP Calculator
// lib/services/rp_calculator.dart — COMPLETE v5
class RPCalculator {
  static const int _BASE = 20;   // normal play base
  static const int _CUP  = 35;   // Royal Cup base
  static const int _GAP  = 4;    // RP per level index difference
  /// Call this after every ranked game.
  /// Both players on the SAME team pass the SAME teamAvgRP values.
  static int calculate({
    required bool won,
    required int  myTeamAvgRP,
    required int  oppTeamAvgRP,
    required int  winStreak,
    required bool isCupMatch,
    required bool isBotOpponent,
  }) {
    // Bot handling
    if (isBotOpponent) return won ? 5 : 0;
    final base = isCupMatch ? _CUP : _BASE;
    // Map averages to level index 0-5
    final myIdx  = RankSystem.getLevelInfo(myTeamAvgRP).level.index;
    final oppIdx = RankSystem.getLevelInfo(oppTeamAvgRP).level.index;
    final gap    = (oppIdx - myIdx).clamp(-3, 3);
    if (won) {
      int rp = base + (gap * _GAP);
      // Small streak bonus: max +4 RP (capped)
      rp += winStreak >= 5 ? 4 : winStreak >= 3 ? 2 : 0;
      return rp.clamp(8, isCupMatch ? 47 : 32);
    } else {
      int rp = -(base + (gap * _GAP));
      return rp.clamp(isCupMatch ? -47 : -32, -8);
    }
  }
  /// Returns the team average RP for use in RP calculation.
  static int teamAverage(int player1RP, int player2RP) {
    return ((player1RP + player2RP) / 2).round();
  }
}

9a. CupService — Royal Cup Logic
// lib/services/cup_service.dart
class CupService {
  static const int MAX_CUP_ENTRIES_PER_DAY  = 4;
  static const int EXTRA_TICKET_GC_COST      = 100;
  static const int DAILY_RP_CAP_FROM_CUP     = 100;
  static const int MIN_RP_FOR_CUP             = 300; // متوسط I
  /// Returns true if player can enter a Cup match.
  static CupEntryResult canEnterCup(PlayerStats s) {
    if (s.totalRP < MIN_RP_FOR_CUP)
      return CupEntryResult.insufficientRank;
    if (_entriesUsedToday(s) >= MAX_CUP_ENTRIES_PER_DAY)
      return CupEntryResult.dailyCapReached;
    if (s.cupTickets <= 0)
      return CupEntryResult.noTickets;
    return CupEntryResult.allowed;
  }
  /// Call when player wins or loses a Cup match.
  /// Applies RP change but respects daily cap on gains.
  static int applyCupResult(PlayerStats s, int rawRPChange) {
    s.cupEntriesUsedToday++;
    s.cupTickets--;
    if (rawRPChange > 0) {
      final remaining = DAILY_RP_CAP_FROM_CUP - s.cupRPGainedToday;
      final actual = rawRPChange.clamp(0, remaining.clamp(0, 999));
      s.cupRPGainedToday += actual;
      s.totalRP = (s.totalRP + actual).clamp(0, 99999);
      return actual;
    } else {
      s.totalRP = (s.totalRP + rawRPChange).clamp(0, 99999);
      return rawRPChange;
    }
  }
  /// Reset daily Cup counters — call at midnight.
  static void resetDailyCupCounters(PlayerStats s) {
    s.cupEntriesUsedToday = 0;
    s.cupRPGainedToday = 0;
    // Subscription gives 2 tickets; unused tickets expire
    if (SubscriptionFeatures.isActive(s))
      s.cupTickets = 2; // reset, not add
  }
  static int _entriesUsedToday(PlayerStats s) => s.cupEntriesUsedToday;
}
enum CupEntryResult { allowed, insufficientRank, dailyCapReached, noTickets }

// lib/services/progression_service.dart
// Call processGameResult() after EVERY ranked or Cup game.
class PostGameResult {
  final int     rpChange;
  final int     newRP;
  final String  newLevel;       // e.g. "خبير III"
  final bool    leveledUp;      // crossed to new main level
  final bool    promoTriggered; // Promotion Series starts now
  final ChestType chest;
  final List<int> missionRPEarned; // RP from completed missions
  final int     gcEarned;       // Golden Cards from gameplay
  final bool    isCupMatch;
  PostGameResult({required this.rpChange, required this.newRP,
    required this.newLevel, required this.leveledUp,
    required this.promoTriggered, required this.chest,
    required this.missionRPEarned, required this.gcEarned,
    required this.isCupMatch});
}
class ProgressionService {
  static PostGameResult processGameResult({
    required PlayerStats stats,
    required bool  won,
    required int   myTeamAvgRP,
    required int   oppTeamAvgRP,
    required bool  isCupMatch,
    required bool  isBotGame,
    required bool  wasKaboot,
    required bool  balootDeclared,
    required bool  sawaWin,
    required bool  qaidWon,
    required bool  isHakamMode,
  }) {
    stats.totalGamesPlayed++;
    stats.lastRankedGameDate = DateTime.now();
    // ── Placement match logic ───────────────────────────────
    if (stats.inPlacement && !isCupMatch) {
      stats.placementsThisSeason++;
      if (won) stats.totalWins++;
      if (stats.placementsThisSeason >= 5) {
        stats.inPlacement = false;
        stats.totalRP = _placementRP(stats);
      }
      return _placementResult(stats);
    }
    final oldRP    = stats.totalRP;
    final oldLevel = RankSystem.getLevelInfo(oldRP).level;
    // ── Calculate RP change ────────────────────────────────
    final rawRP = RPCalculator.calculate(
      won: won, myTeamAvgRP: myTeamAvgRP,
      oppTeamAvgRP: oppTeamAvgRP, winStreak: stats.winStreak,
      isCupMatch: isCupMatch, isBotOpponent: isBotGame,
    );
    // ── Apply RP ───────────────────────────────────────────
    int actualRP;
    if (isCupMatch) {
      actualRP = CupService.applyCupResult(stats, rawRP);
    } else {
      actualRP = rawRP;
      stats.totalRP = (stats.totalRP + rawRP).clamp(0, 99999);
    }
    // ── Update counters ────────────────────────────────────
    if (won) { stats.totalWins++; stats.winStreak++; }
    else      { stats.winStreak = 0; }
    // ── Golden Cards for gameplay (NOT RP bonuses) ─────────
    int gcEarned = 0;
    if (wasKaboot && won)  gcEarned += 5;
    if (balootDeclared)    gcEarned += 2;
    if (sawaWin && won)    gcEarned += 3;
    if (qaidWon)           gcEarned += 2;
    stats.goldenCards += gcEarned;
    // ── Peak RP tracking ───────────────────────────────────
    if (stats.totalRP > stats.peakRPThisSeason)
      stats.peakRPThisSeason = stats.totalRP;
    // ── Chest ──────────────────────────────────────────────
    final newLevel = RankSystem.getLevelInfo(stats.totalRP).level;
    final leveledUp = newLevel.index > oldLevel.index;
    final chest = ChestService.checkAndAward(stats,
                    isRankMilestone: leveledUp);
    // ── Promotion series trigger ───────────────────────────
    bool promoTriggered = false;
    if (!isCupMatch && !stats.inPromotionSeries
        && RankSystem.isInPromotionZone(stats.totalRP)
        && stats.totalRP > oldRP) {
      stats.inPromotionSeries = true;
      stats.promoWins = stats.promoLosses = 0;
      promoTriggered = true;
    }
    // ── Missions ───────────────────────────────────────────
    final missionRP = MissionService.updateAfterGame(stats,
      won: won, wasKaboot: wasKaboot,
      balootDeclared: balootDeclared, isHakamMode: isHakamMode,
      winStreak: stats.winStreak);
    return PostGameResult(
      rpChange: actualRP, newRP: stats.totalRP,
      newLevel: RankSystem.getLevelInfo(stats.totalRP).display,
      leveledUp: leveledUp, promoTriggered: promoTriggered,
      chest: chest, missionRPEarned: missionRP,
      gcEarned: gcEarned, isCupMatch: isCupMatch);
  }
  static int _placementRP(PlayerStats s) {
    // Wins in 5 placement games map to starting RP
    const table = [0, 100, 300, 600, 1000, 1500];
    return table[s.totalWins.clamp(0, 5)];
  }
  static PostGameResult _placementResult(PlayerStats s) =>
    PostGameResult(rpChange:0, newRP:s.totalRP,
      newLevel:RankSystem.getLevelInfo(s.totalRP).display,
      leveledUp:false, promoTriggered:false,
      chest:ChestType.wood, missionRPEarned:[],
      gcEarned:0, isCupMatch:false);
}
